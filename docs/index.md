# 歡迎來到 Pocketx SDK Documentation！

Pocketx 提供 Python 與 C# 兩種 SDK，供投資人透過 API 進行台股證券交易。兩種 SDK 連接同一套下單服務。

同一頁的範例可用 **Python** / **C#** 分頁切換。選取其中一種語言後，該頁其他範例會跟著切換。

## 環境

- Python：3.9，安裝指令 `pip install pocketx`
- 憑證簽章：Windows
- C# SDK：Windows

## 目前提供的功能

- 登入、帳號、登出
- 商品檔
- 證券下單、改價、改量、刪單
- 委託狀態更新、委託回報
- 銀行餘額、未實現損益、已實現損益、交割款
